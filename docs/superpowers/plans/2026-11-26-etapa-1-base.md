# Etapa 1 – Base do sistema: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objetivo:** criar a base do Fiscaliza.ai com conexão ao banco, funções de segurança e utilitárias, cabeçalho e rodapé padrão e uma página inicial funcionando, para que as etapas seguintes (contas, admin, denúncias, agente, relatórios) sejam construídas em cima dela.

**Arquitetura:** PHP 8 **procedural**: só funções e `require_once`, nenhuma `class`. Cada responsabilidade fica em um arquivo de funções em `includes/`. As páginas são arquivos `.php` que incluem esses arquivos, o cabeçalho e o rodapé. Os testes são scripts PHP de linha de comando com um executor próprio, sem frameworks.

**Tecnologias:** PHP 8.2 (XAMPP), MariaDB 10.4, extensão `mysqli` (estilo procedural), Bootstrap 5.3 e Bootstrap Icons via CDN jsDelivr.

**Especificação:** `docs/Relatorio_Fiscaliza.ai.docx` (seções 2, 3, 4 e 5) e `database/fiscaliza.sql`.

## Restrições globais

- PHP **obrigatoriamente procedural**: nenhuma declaração `class`, `interface`, `trait` ou `new` de classe própria. As funções nativas do `mysqli` são usadas no estilo procedural (`mysqli_prepare`, não `$conn->prepare`).
- **Toda** consulta com valor variável usa `mysqli_prepare` + `mysqli_stmt_bind_param`.
- **Toda** saída de dado no HTML passa por `e()`.
- Senha: `salt = hash('sha256', strtolower(trim($email)))`, `senha_hash = hash('sha256', $salt . $senha)`, comparação com `hash_equals`.
- Charset `utf8mb4` na conexão e `<meta charset="utf-8">` em todas as páginas.
- Cabeçalho e rodapé **idênticos** em todas as páginas, via `includes/cabecalho.php` e `includes/rodape.php`.
- Fundo da interface claro e marca "Fiscaliza.ai". Os nomes de níveis são `cidadao`, `agente` e `admin`; os nomes de status são `pendente`, `rejeitada`, `aberta`, `em_andamento` e `resolvida` (iguais ao ENUM do banco).
- Status públicos (visíveis a todos): `aberta`, `em_andamento` e `resolvida`.
- Os comandos `git` de cada tarefa são executados pelo Bruno (aprendizado). A pessoa que implementa só indica os comandos.

## Pontos de atenção na revisão

1. **MySQL desligado:** abrir o site deve mostrar uma página amigável ("Não foi possível conectar ao banco de dados"), sem mensagem técnica, caminho de arquivo ou senha. Verificação manual na Tarefa 5.
2. **Acentos:** nomes como "Jardim Ártico" e "Iluminação pública" precisam aparecer corretos, sem `Ã`. Teste `conexao_le_acentos` na Tarefa 1.
3. **Banco sem denúncias:** a página inicial mostra os números zerados e uma mensagem de "nenhuma denúncia publicada ainda", sem erro. Teste `estatisticas_banco_vazio` na Tarefa 5.
4. **Nível sem permissão:** quem não tem o nível certo é redirecionado com uma mensagem, não recebe página em branco. Teste `nivel_permitido_*` na Tarefa 3.
5. **Formulário sem token CSRF ou com token errado:** a requisição é rejeitada. Teste `csrf_*` na Tarefa 3.

### Task 2 (Tarefa 2): Funções utilitárias

**Arquivos:**
- Criar: `includes/funcoes.php`
- Teste: `tests/test_funcoes.php`

**Interfaces:**
- Produz:
  - `e(?string $texto): string`: `htmlspecialchars($texto ?? '', ENT_QUOTES, 'UTF-8')`;
  - `limpar_texto(?string $texto): string`: `trim`, `strip_tags` e troca de sequências de espaços em branco por um espaço;
  - `somente_digitos(?string $texto): string`;
  - `validar_cpf(?string $cpf): bool`: aceita com ou sem máscara, rejeita tamanho diferente de 11 e dígitos todos iguais, e calcula os 2 dígitos verificadores;

  - `redirecionar(string $url): never`, que faz `header('Location: ' . $url)` e `exit`.

### Task 3 (Tarefa 3): Segurança (senha, CSRF, sessão e níveis)

**Arquivos:**
- Criar: `includes/seguranca.php` (inclui `funcoes.php`)
- Teste: `tests/test_seguranca.php`

**Interfaces:**
- Consome: `flash_definir`, `redirecionar` (Tarefa 2).
- Produz:
  - `iniciar_sessao(): void`: se a sessão ainda não estiver ativa, define o cookie com `httponly=true`, `samesite='Lax'` e `secure` conforme HTTPS, e chama `session_start()`;
  - `gerar_hash_senha(string $email, string $senha): string`, com a fórmula das restrições globais;
  - `verificar_senha(string $email, string $senha, string $hash_salvo): bool`, usando `hash_equals`;
  - `csrf_token(): string`: cria `$_SESSION['csrf']` com `bin2hex(random_bytes(32))` se ainda não existir e o retorna;
  - `csrf_campo(): string`: `<input type="hidden" name="csrf" value="...">`;
  - `csrf_validar(?string $token): bool`: `false` se a sessão não tiver token ou se `$token` for vazio ou diferente (`hash_equals`);
  - `login_usuario(array $usuario): void`: `session_regenerate_id(true)` e grava `$_SESSION['usuario'] = ['id','nome','nivel']`;
  - `usuario_logado(): ?array`;
  - `nivel_permitido(?array $usuario, array $niveis): bool`: `false` para `null`, e `true` se `$usuario['nivel']` estiver em `$niveis`;
  - `exigir_login(): void`: se ninguém estiver logado, mostra o flash `warning` "Faça login para continuar." e redireciona para `/fiscaliza/auth/login.php`;
  - `exigir_nivel(array $niveis): void`: chama `exigir_login()`; se o nível não for permitido, mostra o flash `danger` "Você não tem permissão para acessar esta página." e redireciona para `/fiscaliza/index.php`.

- [ ] **Passo 1: escrever os testes**
  - `hash_admin_inicial`: `gerar_hash_senha('admin@fiscaliza.ai', 'Admin@123')` é igual a `'2a8af6198ce9ed8a2b831d03d90c0780b757f8fa5c7d6fc154ff356eab539094'` (o mesmo valor gravado pelo script SQL);
  - `hash_ignora_maiusculas_e_espacos_do_email`: `gerar_hash_senha(' ADMIN@Fiscaliza.ai ', 'Admin@123')` é igual ao valor acima;
  - `hash_muda_com_login`: o mesmo par de senha com e-mails diferentes gera hashes diferentes;
  - `verificar_senha`: `true` para a senha certa e `false` para `'admin@123'`;
  - `csrf_valido`: com `$_SESSION = []`, `csrf_validar(csrf_token())` é `true`;
  - `csrf_invalido`: `csrf_validar('x')`, `csrf_validar('')` e `csrf_validar(null)` são `false`, e com `$_SESSION = []` (sem token gerado) `csrf_validar('abc')` também é `false`;
  - `nivel_permitido_sim`: `nivel_permitido(['nivel'=>'agente'], ['agente','admin'])` é `true`;
  - `nivel_permitido_nao`: `nivel_permitido(['nivel'=>'cidadao'], ['agente','admin'])` e `nivel_permitido(null, ['admin'])` são `false`.
